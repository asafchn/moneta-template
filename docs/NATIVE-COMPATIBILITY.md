# Native installation and generated runtimes

The template repository distributes moneta-setup for Codex and Claude Code. Each installer exposes only init and bundles both runtime templates. The standalone distribution/moneta-setup skill supports skills.sh; its root entry contains every dependency so copying a single skill is sufficient. The skills CLI installs that setup skill; init performs native runtime installation.

The generated user repository contains both host packages, native marketplace metadata, a purpose-specific README and reviewed memory areas. Its runtime exposes evolve, evolve-agent, evolve-evaluate, evolve-message, extend and knowledge-search. Runtime skills have shared setup references under resources/setup but no second discovered init. Each instance receives a stable repository-specific plugin/marketplace identity.

Init installs and enables the active host package using supported native CLI operations. Codex plugin add and plugin list verify installation/enabled state; the inspected CLI has no plugin enable subcommand. Claude supports plugin install and plugin enable at user scope. Hook trust remains controlled by the host; no trust bypass is bundled. Start a fresh chat after installation. A pending graph setup PR/MR still requires human merge before ordinary retrieval.

For organization scope, moneta.json stores exact user-supplied host/namespace rules. The local hook reads only the open repository's Git origin with a bounded, no-includes config query. No organization query, repository listing, network call, source-code read or graph scan occurs in the hook. Subgroups and future repositories match the same namespace boundary. Local legacy connections can override only through explicit, compatible selection. Overlapping installed runtimes require selection; their graphs are never combined.

Each host registers SessionStart, UserPromptSubmit, SubagentStart and PreToolUse. Context prompts the next model request to invoke the originating runtime's qualified skill. It does not prove retrieval completed before a pending tool. The English feedback heuristic examines only a bounded prompt field and does not emit its text; one-message skill triage decides actual relevance. Ordinary requests, opt-outs and unsupported messages stop without graph work.

Claude discovers bundled Markdown agents. Codex uses native child delegation with bundled role instructions; optional explicit project TOML registration preserves existing files. Organization matching does not require editing every project's agent configuration.

Provider checks use the bundled redacting wrapper. A sandbox network block or invisible credential store is retried through approved access before diagnosing login. A genuine missing/rejected credential can start browser login in a separate user-controlled Windows console; other hosts use an interactive terminal fallback. Device codes and credentials stay outside captured chat. Read-only provider permissions are valid: init prepares local artifacts, reports blocked writes/manual steps and resumes later. See [secret handling](SECURITY.md).
