# Implementation standards

- TypeScript ESM, strict checking, validate data at public filesystem/process/MCP boundaries.
- Public contracts follow SPEC.md terminology. Test through public operations, with concrete user scenarios and actual temporary files where practical.
- Keep query generation and contextual relevance judgments in the native agent. Fixed tools perform deterministic primitives.
- Use argument arrays for external processes. Keep transcript text and review bodies out of interpolated shell commands.
- Writes are confined to configured roots. Preserve unrelated files and unmanaged instruction content. Reject stale proposal bases and invalid graphs before publication.
- Keep imported claims, evaluator assessments, and measured outcomes distinct.
- No model provider client, automatic merge, fabricated verification, or silent host-UX fallback.
