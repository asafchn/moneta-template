---
name: moneta-show
description: Open a read-only localhost canvas viewer of the user's selected Moneta knowledge graph, including node details and named edges.
---

1. Resolve [this runtime connection](../knowledge-search/references/connection.md) and [memory selection](../knowledge-search/references/memory-scope.md). Omission selects general; an explicit agent-slug selects only that area. Use the verified [reviewed checkout](../knowledge-search/references/reviewed-state.md), or a specifically requested candidate checkout clearly labeled as such. Completion: one authorized absolute memory-area path is known; never combine areas.
2. Start `node <this-skill>/scripts/server.cjs --area <absolute-area-path>` using the host's background process facility. The bundled viewer needs Node.js only. On Windows, use a hidden background window; retain its process ID and direct output to a private local log. The server prints a localhost URL and opens the browser. If browser launch fails, give that URL to the user. Avoid printing node bodies, authentication output or raw parser diagnostics in chat.
3. Confirm the local `/health` endpoint responds before reporting success. The viewer reads only direct Markdown nodes in the selected area's registered type directories. It shows a snapshot, supports search, node selection and named inverse edges, and reloads that area when Refresh is clicked. A graph read error leaves the prior snapshot labeled as stale; surface the viewer's concise status.
4. Tell the user the selected area, local URL, and how to stop the retained process. Stop only this viewer when asked; never kill unrelated Node processes. The server also expires after eight hours. Completion: the user's actual graph is visible, or the specific launch/read blocker is stated.

The server binds only to 127.0.0.1, uses bundled static assets, and has no graph-writing endpoints. It performs no provider calls, telemetry upload, organization discovery, dependency download or credential probing. Redaction is best effort; this is a private local view, not a public share link. Evaluation records and raw run telemetry stay outside this view. Legacy relations may be displayed with a migration notice; viewing never rewrites them. Schema changes and ambiguous edge meanings belong to extend and human review.
