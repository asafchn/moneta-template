---
name: evolve-message
description: Distill reusable guidance from one user correction, code-review change request, guideline or tool-use explanation, after a quick relevance check.
---

1. **Triage, without tools.** Inspect the one selected user message and already-visible task context. Continue only if it teaches a reusable responsibility, practice, constraint or procedure with a concrete scope. Routine requests, quoted examples, one-off choices, acknowledgments and unsupported guesses end here. Respect active user opt-outs, including earlier instructions scoped to this session or agent. Completion: either stop quietly or state one candidate lesson and why it may recur; no graph edits or review have started.
2. **Bound the evidence.** Follow [single-message evidence](references/evidence.md). Resolve the already-configured domain/agent; automatic runs with missing setup or ambiguous identity defer without creating a repository. Completion: one exact source message, its occurrence/context and scope are retained privately. Keep implementing the user's current request; run this bounded analysis in a native child or at the next natural checkpoint.
3. **Check existing knowledge.** Invoke `knowledge-search` against reviewed state. Identify whether the lesson is missing, already known but undiscovered, misapplied, or task-specific. Check existing local message assessments and open reviews for this same occurrence/lesson. Completion: stop with no change if covered, or identify the exact existing node/update or justified new node. Reuse pending work; a repeated sentence alone does not identify the same occurrence.
4. **Draft one message's change.** Create a separate candidate checkout from the reviewed base. Invoke `evolve-agent` with `source-mode: single-message`, the bounded evidence packet, active identity, source locators and candidate path. Follow its [single-message role scope](../evolve-agent/references/single-message.md). Completion: exact scoped diff or supported no-change result. Analyze only lessons supported by the selected message; broader session evolution is a separate user request.
5. **Evaluate and propose.** Follow [candidate review](../evolve/references/review-candidate.md), preserving `source-mode: single-message` in the assessment and review body. Completion: assessed MR/PR or a supported no-change/deferred result. Summarize the outcome briefly after handling the user's correction; shared activation still requires human merge.

The hook is a fast candidate screen. This skill determines whether reusable guidance merits a proposal; neither stage proves a future performance gain. Direct invocation can inspect feedback missed by the hook.
