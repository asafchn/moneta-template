# Initialize one memory area

1. Retain the parent's selection from [memory selection](../../knowledge-search/references/memory-scope.md). No agent-slug means `memory/general/`; an explicit slug means `memory/<agent-slug>/`. Inspect only that area's indexes if present. For agent-specific enrollment, use the selected slug for its responsibility node. General may have role bindings when explicitly enrolled; an empty general agent index is valid.
2. Create a candidate checkout from the reviewed base. For a new area, copy `assets/graph/general/` relative to init into the selected path. Starter responsibility nodes illustrate formats, not real enrollments: instantiate only actual roles, remove unused sample roles and their inverse entries, and retain shared starter guidance/domain facts only when applicable. Preserve every other area unchanged. Rebuild the selected area's node and agent indexes from retained frontmatter.
3. If a role is supplied, read its instructions and distill responsibilities with source pointers; connect applicable local skills, flows and guardrails using mirrored edges. Store supported facts as sourced domain-knowledge nodes. General without a role can still initialize schemas/indexes and relevant starter content. Record no fictional role binding.
4. Invoke evolve-evaluate with selected memory-scope, actor identity (or unassigned), reviewed/candidate paths, exact diff and a separate evaluation directory. Validate the selected area's nodes, schemas, both indexes and incoming/outgoing edges. Verify the diff touches no other area's memories.
5. Follow [hosted review](../../evolve/references/hosted-review.md), targeting the personal repository. Reuse a pending initialization review for this area. Completion: review contains only assessed initialization and applicable role changes; shared activation awaits human merge.
