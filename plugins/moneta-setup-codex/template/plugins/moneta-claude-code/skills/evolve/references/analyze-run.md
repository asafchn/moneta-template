# Analyze a current or captured run

Retain and pass the originating runtime root, profile path, resolved connection and explicit agent-slug to every nested skill or child. Resolve bundled roles/skills from that exact root; never locate a same-named skill in another installed instance.

Reach this flow after evolve selects whole-run analysis. Retain its chosen source and explicit agent-slug; a single-message correction uses evolve-message instead.

1. Resolve [the runtime connection](../../knowledge-search/references/connection.md) and apply [memory selection](../../knowledge-search/references/memory-scope.md). Verify and refresh the reviewed base through [reviewed state](../../knowledge-search/references/reviewed-state.md). Create a separate candidate worktree/checkout, under that connection's private candidates directory. Preserve the reviewed retrieval checkout and unrelated work.
2. When resuming a pending record, use its frozen source and original session boundary; do not capture the current conversation again. Otherwise, for a saved run, use the supplied file, including plain `.txt` from outside the plugin. For the current run, use an available native transcript export or capture the visible request, role instructions, actions, artifacts and human corrections privately. Mark incomplete capture and retain exact locators. Preserve original sources; do not reconstruct missing history or hidden reasoning.
3. Invoke [evolve-agent](../../evolve-agent/SKILL.md) in a dedicated native child with `source-mode: session`, explicit `agent-slug: <selected-slug>`, actor, source path, coverage limits, reviewed graph/base revision, separate candidate path, relevant role revisions and expected outcome. The child follows [the analysis role](../../evolve-agent/references/role.md); it does not automatically inherit the source session.
4. Inspect the returned analysis against the original request and applicable instructions. Supported changes may update nodes, descriptions, relationships or schemas only in the selected area. Skills-type nodes can hold procedure guidance; shared native plugin changes need a separate user-scoped request. A supported no-change result is valid.
5. Follow [candidate review](review-candidate.md) with `source-mode: session` and the same memory selection. Completion: an assessed review request, supported no-change result or explicit publication limitation. Human merge activates reviewed knowledge; it does not establish future performance gains.
