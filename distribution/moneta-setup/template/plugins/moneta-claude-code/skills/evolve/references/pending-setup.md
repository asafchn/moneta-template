# Preserve learning while setup is pending

Reach this branch only after evolve has selected a learning flow and found missing setup. Save the source before entering the wizard so later work cannot redefine it.

1. Create a private pending directory under `.moneta-local/pending/` after verifying it is ignored by the consuming repository. Otherwise use a private temporary directory and report its location. Keep both source and pending record out of the bootstrap/knowledge publication tree and ordinary search.
2. Freeze the selected evidence. For one message, save its exact text, occurrence/session locator and necessary already-visible context. For a saved run, preserve an unchanged private copy and record original path plus file hash/revision. For the current run, record the source session and last included turn/occurrence, then save the available transcript or a bounded snapshot through that point, before wizard exchanges begin. Mark missing coverage; never reconstruct hidden or unavailable history. Retain relevant role/artifact revisions or available snapshots and their limitations.
3. Write a Markdown pending record beside the source: selected flow/source-mode, explicit agent-slug and memory-scope, actor if known, source path and version/hash, occurrence or run boundary, capture limits, retained role/artifact references, and setup status. This record is a routing/source receipt, not an evaluation result. No assessment contents belong here.
4. Enter init with that record retained. If setup pauses, update it with the personal repository and setup PR/MR when known; return its path and the exact pending action. Do not read unmerged memory as approved or reselect a later correction as the source.
5. On resume, load the named pending record, verify the retained source still matches and that reviewed setup is available, then dispatch the saved flow with its original source boundary and explicit agent-slug. A saved current-run snapshot is passed as the session source; do not capture the now-current conversation. Missing, changed or incomplete evidence stays an explicit limit; ask for the intended source if it cannot be recovered. Mark the receipt completed or no-change when that flow finishes.
